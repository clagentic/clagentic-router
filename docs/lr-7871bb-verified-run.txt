=== What this establishes ===

- --safe-mode alone leaves the permissions.allow gap OPEN (probe=run with
  the rule present).
- --setting-sources user CLOSES it (probe=deny), and the causality cells
  prove the project source is the variable: user -> deny,
  user,project -> run, project -> run.
- --setting-sources user ALSO suppresses project hooks and CLAUDE.md
  auto-discovery -- so it covers everything --safe-mode covers, plus the
  gap --safe-mode misses.

Decision: claude_cli and codex_subagent now ship --setting-sources user
alone (--safe-mode dropped, not stacked). --setting-sources user covers
everything --safe-mode covered and closes the gap it left open; dropping
--safe-mode also means legitimate user-level customizations (e.g. the
operator's own user-scope permissions.allow entries) still apply, where
--safe-mode would have discarded those too.
